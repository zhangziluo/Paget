Paget 使用手册

这本手册讲的就是你正拿着的这个软件：整间书房怎么用、阅读页那两栏各管什么、设置都在哪儿、
遇到问题时去哪儿看。它是开发用的书架上默认唯一的一本书（npm run tauri dev），
所以你可以边读边对着界面点。

手册里凡是提到「数据目录」，指的是内核放书库、正文、进度与成就的那个文件夹：
　· 开发时（npm run tauri dev）：项目里的 .wreader/
　· 装出去的 app：macOS 是 ~/Library/Application Support/com.paget.gui/core，
　　Windows 是 %LOCALAPPDATA%\com.paget.gui\core
两处都是纯文本（JSON / TOML）加一堆 UTF-8 的正文文件，复制走就是备份 —— 不存在云上，也不上传。

前言

Paget 是一台装在电脑里的书房：一间画出来的屋子，墙上挂着便利贴与钟，架子上摆着一排书脊。
它只做一件事，但做得挺细：把你自己的电子书收进一个本地书库，记住你读到哪一行、读了多久、
解锁了哪些成就，并且在你关掉它之后把这些一个不落地留在你自己机器上。

它有三个部分（这是「为什么它这么稳」的原因，不必记住）：

　· 界面（React）：只负责画。所有规则（百分比怎么算、时间戳什么格式、章节怎么认）都问内核，
　　界面自己不算一遍，免得两处算法慢慢走偏。
　· 壳（Rust / Tauri）：转发界面与内核之间的每一次读写，另外管三样可以随时丢掉的东西：
　　封面缓存、正文全文索引、以及限时书到期后的归档包。
　· 内核（Python，随包冻成 paget-core）：拥有数据的那个。书库、正文、阅读位置、时长、
　　统计与成就全写在它管的那个数据目录里。

所以：缓存删了不心疼（下一次启动它会自己重建），数据目录千万别随手删（那里是全部家当）。

这本手册按「你实际会怎么用」的顺序写：先认书房，再学怎么读、怎么调好看、怎么让光点陪读、
怎么让书自己往前翻、PDF 怎么看、统计与成就在哪、设置与数据怎么管、限时书怎么封印与找回，
最后是键位总表与常见问题。急着用的话，直接跳到第十章那张表也行。


第一章 先读起来：书房、书架与导入

一进屋就是这个「书房」——它不是装饰，就是首页。这一页只有三类东西：

　· 一面书架：你的书脊整整齐齐码在上面。书脊的厚薄按每本的总字数算（字数多的厚一点），
　　一排摆几本也跟着重算，所以看着错落；颜色由书自己定，不重复。
　　（想让它一律等宽：设置 →「书架的样子」→ 关掉「书脊厚薄跟着字数走」。）
　· 墙上：四枚便利贴（统计 / 成就 / 设置 / 沉浸）与几样小挂件。点便利贴就展开那一整页，
　　页里按 Esc 或点「返回书架」回来。「沉浸」那枚不展开页面，它是下一节说的开关。
　· 架子最前面一只藤条篮子：那是「导入电子书」的入口，点它会弹出系统原生的文件浏览器。

屋子还有一点声音：打开就在响，白天是「风铃流水」、夜里是两段「虫鸣」交替（按系统时间，
6 点天亮、18 点天黑，到点自己换）。点书架上层那台留声机会弹出曲目面板：最上面是开 / 关，
下面列出九段声音 —— 点哪一首就单曲循环哪一首，最后一项「按昼夜自动」回到跟着天色走；
响着的时候喇叭口有一圈很淡的暖光在呼吸。设置 →「书房的声音」里也有同一个开关，在哪儿点都一样。
每一遍的开头和结尾各有 200ms 的淡入淡出，循环接缝处不会「咔」一声。
声音文件随应用打包在本机，不用联网；开着的时候软件一启动就有，
要是系统还没让出声，随便点一下窗口（点书、翻页都算）就会响。

怎么导入一本书：点篮子 → 选文件。macOS 上弹出的是一整块系统面板，文件与文件夹同框、都能多选；
Windows / Linux 的系统对话框做不到同框，所以会先问一句「选文件（可多选）」还是「选一个文件夹」
（选文件夹时内核会递归找全里面的书）。认得的格式由内核决定：.txt、.epub、.mobi、.azw3、.pdf。
导入后新书的封面会一本本从篮口飞上架，想跳过按 Esc 或点一下屏幕。
（不喜欢这段飞行：设置 →「书架的样子」→ 关掉「导入时让封面飞一下」。）

PDF 是例外，而且是有意的：它默认按图片读（见第六章），导入时只收文件、数页数、取一张封面，
几百页的书一两秒就完事；要读文字得自己按一下「转换成文字」。

书架上的操作，最常用的是右键（触屏长按 550 毫秒）一枚书脊：

　· 继续阅读 —— 直接翻到上次读到的那一行；
　· 阅读统计 —— 这本书读了多久、打卡几天；
　· 属性 —— 书名 / 作者 / 标签 / 总字数 / 添加时间 / 最后阅读。前三项可以直接改：
　　改完书架立刻更新，正文文件与阅读进度一概不动；
　· 置顶 —— 把它挪到书架最前面（这是界面自己的状态，存在本机，不进书库）；
　· 标记已读 / 标记未读 —— 读完了一本，或者想重新当新书读；
　· 设置限时 —— 见第九章；
　· 删除 —— 会问一次。内核里的这本书与它的正文文件一起走；阅读时长仍然留在统计里。

搜索：按 / 或 ⌘K 唤起搜索框，搜书名、作者与标签。想搜正文得先给这本书「建立索引」
（阅读页那颗「建立索引」，见第二章）；搜索框里打字时那几个单键快捷键都不抢，Esc 关掉搜索。

翻屏：书多了会分成一屏一屏（每屏几排）。← → 是翻一屏，两侧也有 ‹ › 两颗。

管理模式（钥匙是右上角那把锤子，或者直接按 M）：

　· 进入后书脊会轻微「下沉」，这时按住一本往别处拖就是排序；拖到屏幕左右边缘停 0.3 秒会翻屏；
　· 也可以点一下某本书脊选中它（会抬起来 + 描边），再用 ← ↑ → ↓ 一格一格挪位，
　　Esc 放开它（放开后方向键又回到翻屏）；
　· 右上那颗「☑️ 批量编辑」进入选择态：点书脊勾选（可以跨屏多选），然后
　　改书名（前缀 / 后缀 / 查找替换）、标记已读·未读、删除 —— 逐本执行，某一本失败不影响其余，
　　最后一并告诉你哪几本没成；
　· 按那颗「完成」退出管理模式。

沉浸模式（墙上那枚「沉浸」便利贴，点一下开、再点一下关）：

　· 开着的时候只留书架：书打不开、右键菜单不弹，统计 / 成就 / 设置三枚贴纸、右上角的
　　重新同步 / 清缓存 / 搜索、藤条篮子、留声机、玩偶面板全部停用；
　· 只有整理书架照旧：右上角那把锤子（或 M）还能进去拖书、排序、批量编辑；
　· 它是给「坐下来只读书、不被打断」用的，所以退出也只在墙上那枚贴纸上 —— 它开着时会点亮。
　　这个状态不存档，关掉软件再打开就回正常模式。

快捷键（书房与墙上那三页通用）：M 管理模式、S 统计、A 成就、G 设置、Esc 回书房。
另外 / 搜索、← → 翻屏。这些键在输入框里打字时一律让位（Esc 例外，它到哪都是「回来」的意思）。


第二章 读书的样子：阅读页的两栏与键盘

从书架上点开一本（或右键「继续阅读」）就进阅读页：中间是一本翻开的书 —— 左边一条书脊，
右边一张纸，正文一路往下滚；滚到快见底时它自己接下一批，所以一本书能一口气读到书尾。

　· 纸页右上角那枚丝带是书签：点一下插进「你正看着的那一行」，再点一下拔出来。
　　书签写在内核里（与终端阅读器按 b 是同一份），换哪个界面都认。
　· 呼出工具：点屏幕中间那一块（大约中间 50% × 64% 的范围），上下两栏一起滑出来；
　　再点一下中间收起，按 Esc 也是一路往回退（本节最后有它的次序）。
　　（点边缘、点书签、拖选文字都不会误触 —— 那些位置是特意让开的。）

上栏管「这本书 / 我在哪」：

　· ← 书架：先记好读到哪、读了多久、解锁了什么，再回书架（Esc 的最后一步走的也是这条路）；
　· 书名与位置：书名，加上「读到百分之几 · 第几行 / 共几行」；
　　PDF 图片模式那边显示的是「第几页 / 共几页」；
　· 保存位置：把当前这一行立刻存进书库。平时每分钟与离开时都会自动存，这枚是手动保险；
　· 建立索引：给这本书做正文全文索引（书架上搜正文要用）。很长的书只索引前半部分；
　· 快捷键提示：就是下面这份键位；
　· 看图片（PDF 才有）：从文字模式切回图片模式。

下栏管「怎么读」：

　· 自动翻页：免手翻的开关（见第五章）；
　· 目录：内核认出来的章节表，选一章就跳过去（章节按标题的样子认，认法可在设置页调）；
　· 书签：你插过的那些位置，选一个跳回去；
　· 光点导读：开 / 关（见第四章）；
　· 档位：换领路的样式、速度与颜色（按钮上写着当前档，如「10档 · 3.5s/行」）；
　· Aa：排版（字体、字多大、一行多高、纸边留白……见第三章）；
　· 纸色：纸面主题与亮暗（见第三章）；
　· 翻页设置：自动翻页的节奏与抽查，存进书库设置、改完当场生效（见第五章）。

键盘（焦点在输入框 / 下拉框里时不抢；空格落在按钮上时留给那枚按钮）：

　↑ ↓　　翻一行（与终端同一套行号语义，一按一行）
　← →　　滚一屏（空格 / PageUp / PageDown 也一样；Shift + 空格 往回滚）
　1 – 6　　光点导读的六个快捷档（1 最慢、6 最快）
　0　　　开关光点导读
　Esc　　一路往回退：先收面板 → 再收两栏 → 都没有就回书架（记好账再走）

位置与时长是怎么记的：正文里唯一可靠的坐标是「行号」，所以每跳一次、每滚一屏、每分钟自动存一次，
都写同一份进度；离开时再写一条「这次读了多久、读了哪些行」，成就就在那一刻结算。
也就是说，哪怕中途崩了，也只会丢最近一分钟的位置。

Esc 的次序值得单独记一下：它是一条链子 —— 正在调的面板 → 上下两栏 → 回书架。
三级都能一路按 Esc 退出去，不会一按就把整本书关掉；PDF 图片模式同理（它那条顶栏开着时先收顶栏）。


第三章 把纸面调成你喜欢的样子

下栏那颗「Aa」是排版，那颗「纸色」是配色。两项都只改「这台电脑上读起来的样子」，
书库里的文件一个字都不动；点面板外面或按 Esc 收起。

Aa 里能调的（面板里写的都是大白话）：

　· 字体：六款（默认 / 宋体 / 楷体 / 仿宋 / 圆体 / 等宽），都是系统自带、不联网；
　　每枚按钮自己就用那款字体写名字，挑的时候一眼看出差别；
　· 字多大：20 – 80 像素；
　· 笔画多粗：100 – 900（整百档）；
　· 字与字之间：-1 – 6 像素（能收紧一点，也能拉开）；
　· 一行多高：1.2 – 3.4 倍；
　· 两段之间：0 – 2.5 em（段落之间额外留的白，跟着字号缩放）；
　· 左右留白 / 上边留白 / 下边留白：纸边留多少白（像素）；
　· 「上下留白一样多」：勾上之后下边距跟着上边距走；
　· 恢复默认：回到出厂那一套（纸色与字体不动）。

纸色里能调的：

　· 纸的样子：四套预设 —— 羊皮纸（暖米黄，最接近原来的纸色）、护眼绿（豆沙绿）、
　　深空蓝（夜空那种蓝）、代码（点名的 #00008b 底 + #ffffff 字，像代码编辑器）；
　· 白天或夜里：每套预设都有亮暗两版（代码主题亮暗同色，点白天黑夜不会变样）；
　· 底色 / 字色：两枚取色器，选了就盖在预设之上（换预设时它们不会被改动）；
　　「清除自定义色」把这两样清掉，回到跟随主题。

这些偏好存在本机（不是书库里的设置），所以换一本书也是同一个样子。换主题时纸面、书页堆叠、
书口、纸面的光、书脊的暗与正文墨色一起变 —— 上下两栏那块木头不跟着变，它是书房的一部分。


第四章 光点导读：跟着光读

下栏那枚「光点导读」打开之后，会有一位「领路的」沿着你正读的这一行从左往右慢慢走；
一行走完自动换下一行。它走过的地方很快化掉，所以正文里任何一刻只有一小段亮着 —— 看着就像在往前推。

领路的可以换三号（下栏那颗「档位」里选）：

　· 光点：默认，一颗琥珀色小球；
　· 下划线：没有实体的一位 —— 四五个字宽的一小段下划线自己就是领路的（走过就化掉）；
　· 波浪线：同一支笔画的波浪（走法、宽度、快慢与下划线完全一样，只是笔迹不同）。

速度按「每行停留时间」分 20 档：1 档最慢（20 秒一行），20 档最快（0.5 秒一行），默认 10 档约 3.5 秒。
下栏那颗「档位」按钮点开就是滑杆（按钮上写着当前档，如「10档 · 3.5s/行」）；
键盘 1–6 是六个快捷档（1 还是最慢、6 还是最快）。

　· 开关：下栏那枚「光点开 / 光点关」，或者键盘 0；
　· 颜色：档位面板里有三枚「换颜色」文字按钮（光点那颗小球、下划线、波浪线），点一下弹系统取色盘，挑完存本机；
　　「恢复出厂色」回到出厂的三样（光点=琥珀；两条线跟正文同色）；
　· 空行一步跨过去，不花任何时间（空行只是排版留下的缝，在那儿等一整行没有意义）；
　· 正文快见底时它自己接下一批，画面会跟着领路的往前滚，所以那一行一直留在视野上方一小截；
　· 存哪儿：读到哪儿按书存在本机，关掉书再打开会接着导；样式、速度与颜色也是本机（换书一样）。

它与终端阅读器里那套是同一个语义 —— 换句话说，两个界面对「读」这件事的理解是一份。


第五章 免手翻：自动翻页与抽查

免手翻就是让书自己往前走。文字页一次走「一屏行」，PDF 图片模式一次翻一页（或几页）。

　· 打开：下栏那枚「自动翻页」（开着时它写成「停止自动」）；
　· 开着的时候左上角会挂一枚小牌子「自动翻页中 · 每 5 秒 1 行」，节奏一眼可见；
　　点它就直接打开「翻页设置」。

节奏在「翻页设置」里调（存进书库的 settings.toml，与终端是同一份；改完当场生效，
不用关掉书再打开）：

　· 自动翻页：多久走一次 —— 单位是秒，可以写小数（比如 2.5 秒走一次）；
　· 自动翻页：一次走多少 —— 文字是「屏幕行」；PDF 的图片模式是「页」，5 秒一页偏快，
　　读 PDF 时把上一项调到 20–60 秒更舒服；
　· 自动翻页：多久抽查一次 —— 每隔这么多分钟弹一道小题目（填 0 就是从不抽查）；
　· 抽查后等几秒 —— 题目弹出来之后等这么久，一直没人作答，自动翻页就停下来。

那道小题目只是确认你还在看：点哪一个选项都算作答，只有一直没人理才会停下。

几条规矩（与终端阅读器按 a 完全同一套）：打开时先等一整拍才开始（不会一开就把页面抢走）；
你一动手（滚轮、按键、点一下）就把下一次往后推一整拍（人在自己读时，计时器不许抢页面）；
读到书末它自己停下并说一句，不会停在半路一声不响。


第六章 PDF：按图片读，需要时转成文字

PDF 默认按图片读，这是有意的：PDF 本来就是「一页一页怎么印」的描述格式，文字层是副产品
（扫描件根本没有）。所以导入一本 PDF 时只收文件、数页数、取一张封面 —— 几百页一两秒就完事；
几万行的文字层留到你真要读文字时再抽。

图片模式里：

　· 上栏那两颗 − ＋ 是缩放（50% – 250%）；页码写在每一页的右下角，顶栏还有「第几页 / 共几页」；
　· 鼠标滚轮一路往下滚；键盘也一样 —— ↑ ↓ 挪一小步，← → / 空格 / PageUp / PageDown 滚一屏，
　　Shift + 空格 往回滚（与文字阅读页同一套键位）；
　· Esc 与文字页一样是一路往回退：先收「翻页设置」浮层 → 再收顶栏 → 都没有就回书架。

「转换成文字」：上栏那颗按钮，让内核去抽文字层（慢活，几万行要几十秒）。转完直接进文字阅读页。
扫描版会明确告诉你「没有文字层」——那不是出错，是那本书本来就只有图。

转过之后：

　· 书架上右键那本会多一颗「读文字」，一键切到文字模式；
　· 文字模式的上栏里有「看图片」换回来；
　· 这个「按图片读还是按文字读」的看法按书记在本机，下次打开这本书还按它。

进度怎么算：图片模式下「第几页」就是内核里的进度（一页 = 一行），所以统计、成就、书签、
与终端阅读器全都对得上。免手翻在图片模式下一次翻「翻页设置」里那个步长（页）。


第七章 统计与成就

墙上那两枚便利贴（或者按 S / A）：

统计页是一页手绘风的「读书日记」，顺着往下读是四节：

　· 今天：今天读了多久，以及一句「还差多少」—— 按你设的小目标算；
　· 这些天：这一周 / 这个月 / 从第一页到现在各读了多少；末尾一行「软件使用时间」是读书以外
　　在书房、日记、勋章、设置这些页面停留的时长（窗口在前台时才算，翻开一本书之后不算）；
　· 坚持：连着读了多少天、最久的一次、翻开过 / 读完 / 生词 / 译文 / 勋章各多少，
　　还有一句「凌晨还在读」之类的话；
　· 每本书读了多久：一本一条占比条。

小目标在设置里那项「每天的小目标」：一天打算读多少分钟（填 0 就是不定目标）。

成就页是一整块黑漆陈列板与一列金色的铁十字勋章。已授予的镀金，章心是它自己那枚符号，
章底刻着解锁的时间；还没授予的是同一尊生铁；隐藏成就只剩一个问号 —— 解锁之前，它的名字与条件
一个字都不透露（留点惊喜）。

成就由内核判定（一共 45 条）：读了多少行、打卡多少天、连读多少天、凌晨读过、读完一整本、
导入过多少本、去过哪些地方…… 打开阅读器、读够时间、读到书末这些动作都会触发；
解锁那一刻界面上会报一句「新解锁：……」。

其中「🙈 我不看书」看的是「单次」：这一次打开程序之后，不读书地待满一小时，
或者连续开着沉浸模式一小时，都算；关掉程序再开、把好几次的时长加起来不算。
界面每 5 分钟把当前这一次的峰值报给内核，所以勋章页上的进度条会慢慢走。

其中「🌈 五颜六色」要的是颜色：用四种自定义颜色的下划线 / 波浪线 / 光点读完一本书。
阅读页下栏那几枚「换颜色」按钮挑过的颜色按书攒着（同一本书读过几场、换来换去都算数，
出厂色不算），凑够四种、这本书又标了读完（读到最后一行，或在书架上「标记已读」）就解锁。

地理类的勋章要查位置，而查位置要联网 —— 所以那一项单独放在设置里：「要不要联网查位置」。
关掉就完全不联网，这类勋章会一直空着，直到你哪天再打开它。

统计页与成就页的阅读数字都来自内核那一份（统计只有一个来源）；「软件使用时间」是界面自己
记在本机的，只在这台机器上累计。所以换界面、换终端，阅读数字看到的都一样。


第八章 设置与数据：调一调、数据、已归档

墙上那枚「调一调」便利贴（或者按 G）打开三个页签：设置 / 数据 / 已归档。
（按 G 会直接回到「设置」那一页。）

设置页每一项都是三行：大白话的名字（比如「每天的小目标」）、一句解释它干什么、
以及技术名 + 「现在：…」的人话读法 + 保存。开关是勾选框、数字写在横线上；
改完直接写进书库，没有「确定 / 取消」这一步。

哪些项在哪儿露面：

　· 与「正读着书时想调」有关的（自动翻页那几项）在阅读页下栏的「翻页设置」里；
　· 其余（统计口径、正文放哪、章节怎么认、书房的声音、书架的样子）在这里；
　· 只给终端阅读器用的那些项，界面上一个都不列 —— 免得你调半天，其实只影响命令行。

设置页里几项值得单独说：

　· 每天的小目标：见第七章；
　· 要不要联网查位置：见第七章（唯一会联网的一项）；
　· 电子书正文放在哪儿：导入的电子书转成 UTF-8 正文之后放在这个目录，留空就是用默认的；
　　改了只影响以后导入的书，已经在书架上的不会自己搬过去；
　· 章节标题怎么认：内核靠标题的样子认章节（比如「第十二章 出山」）。你的书写法特殊的话，
　　在这里补一个规则（多个用竖线隔开）；留空就只用内核自带那套；
　· 章节缓存放哪儿：章节表、字数这类算出来的东西缓存在这个目录，随时可以删，下次读会自动重建；
　· 书房的声音：白噪音开不开（默认开）、手选了哪一首（默认跟昼夜走）。开着时白天风铃流水、
　　夜里两段虫鸣交替；它和书架上那台留声机是同一个开关（这两样存本机，不进书库）；
　· 书架的样子两枚：书脊厚薄跟不跟字数走、导入时封面飞不飞（这两样存本机，不进书库）。

数据页（都在这一页，每一项都会问一次）：

　· 四个位置：数据目录 / 正文 / 书目 / 设置文件各在哪儿 —— 排查问题时先看这里；
　· 导出：把书单、进度、时长、成就写成一个备份文件；
　· 合并备份：把一份备份并进来（只增不减，不会覆盖你现在的记录）；
　· 清理失效书目：把「正文文件已经不在」的条目清掉（多半是有人手工删了文件）；
　· 清空书库：把所有书都移出书库（阅读时长与成就会留着）。

已归档页：限时书到期封印之后就在这儿（见第九章），可以「找回」—— 回到书架，进度也一起回来。


第九章 限时与封印

有些书你只想让它读一段时间（借来的、试读的、给自己定个期限的）。右键那本书 →「设置限时」，
填一个到期日（形如 2026-10-31）即可。书脊上只标一枚 ⏳，不显示倒计时 —— 不制造焦虑。

到期那天 0 点（书房里那个每秒走的钟会命中它），发生两件事，而且顺序是有意的：

　1. 先把这本书打成一份 zip（正文、进度、书签、与成就相关的记录都在里面），放进应用数据目录的
　　archived/；
　2. 再让内核把它移出书库 —— 于是它从书架上消失了。

也就是说：书不是被删，是被「封印」了。要是你在它封印后又想读：设置 →「已归档」→ 找到它 →
「找回」，它回到书架，读到的位置也一起回来。zip 你自己复制走也行，它就是一个普通文件。


第十章 键位总表

书房（首页）：

　/ 或 ⌘K　　唤起搜索（输入框里打字不抢键，Esc 关掉搜索）
　← →　　　　翻一屏（两侧的 ‹ › 与它同一条路）
　M　　　　　进管理模式（右上角那把锤子也是它）
　S / A / G　　统计 / 成就 / 设置（墙上那三枚便利贴）
　Esc　　　　回书房；在挂件页里是返回；在搜索里是关掉搜索

管理模式里：

　拖书脊　　　排序（拖到屏幕左右边缘停 0.3 秒翻屏）
　点书脊　　　选中它，然后用 ← ↑ → ↓ 一格一格挪位
　Esc　　　　放开手上那本（放开后 ← → 又是翻屏）
　☑️ 批量编辑　进选择态：点书脊勾选 → 改书名 / 标记已读·未读 / 删除

阅读页（文字）：

　↑ ↓　　　　翻一行
　← →　　　　滚一屏（空格 / PageUp / PageDown 也一样）
　Shift + 空格　往回滚一屏
　1 – 6　　　光点导读的六个快捷档
　0　　　　　开关光点导读
　Esc　　　　一路往回退：面板 → 上下两栏 → 回书架

PDF 图片模式：

　↑ ↓　　　　挪一小步
　← →　　　　滚一屏（空格 / PageUp / PageDown 也一样）
　Shift + 空格　往回滚一屏
　Esc　　　　一路往回退：翻页设置浮层 → 顶栏 → 回书架

两句话管住全部：单键在输入框里让位；带 ⌘ / Ctrl / Alt 的组合键一概不碰（留给系统）。


第十一章 常见问题

问：首屏写着「core transport failed: the core exited without answering」。
答：内核没起来（书还在，别慌）。开发时按这三步看：
　　① 内核的解释器在不在：core/.venv/bin/python -m wreader.serve（能挂在那儿等输入就对了，Ctrl+C 退出）；
　　② 不在就装一次：core/.venv/bin/python -m pip install -e core；
　　③ 想用别的解释器：PAGET_CORE_PYTHON=/path/to/python npm run tauri dev。
　装出去的 app 用的是随包那份冻结点内核，正常不会出这条；真出了多半是包里少了 resources/core。

问：书架空了，或者书「不见了」。
答：先看你打开的是哪一份数据 —— 开发（项目里的 .wreader/）与装出去的 app
（macOS ~/Library/Application Support/com.paget.gui/core）是两份独立的书库。
想让某一边指向另一边，设 WREADER_HOME 指到那个数据目录即可。
另外：数据目录千万别删；缓存（cache.sqlite3、covers/、章节缓存）删了没事，会自动重建。

问：搜不到正文。
答：给这本书「建立索引」（阅读页那颗按钮）。很长的书只索引前半部分 —— 这是有意的，免得占太多地方。

问：点「转换成文字」说没有文字层。
答：那是扫描版 PDF（里面就是一张张图），没有文字可抽。按图片读它照样能读。

问：想清掉一本书 / 全部清掉。
答：一本：右键 → 删除。全部：设置 → 数据 → 清空书库（阅读时长与成就会留着，不白读）。

问：换台机器 / 想备份。
答：整个数据目录复制走就是完整备份。也可以「数据 → 导出」写一份备份，在另一台上「合并备份」并进去
（只增不减，不会覆盖那边的记录）。

问：阅读时长与成就能搬走吗。
答：能 —— 同上那条：导出 / 合并备份，搬的就是时长与成就。

问：想要的字体 / 字号 / 纸色在设置页里找不到。
答：它们在阅读页：点屏幕中间呼出两栏 → 下栏那颗 Aa（字）与「纸色」（配色）。这两样只影响这台电脑，
不进书库。


后记 它是什么做的、东西都在哪儿

外面是 Tauri：Rust 写的一层壳，加系统自带 WebView 里跑着的 React 界面。
里面是 Python 写的内核（打包时冻成一个可执行文件随包分发），所以用户机器上不需要装 Python。

文件都在哪里：

　数据目录（你的全部家当）
　　settings.toml　　设置（含自动翻页那几项）
　　library.json　　 书单与每本书的进度、统计、书签
　　achievements.json　成就与解锁时间
　　shelf.json　　　 书架布局（顺序）
　　novels/　　　　　正文（UTF-8 的 .txt）与旁边的封面图
　应用数据目录（可以重建的那部分）
　　cache.sqlite3　　书架快照、正文全文索引、界面自己的设置（删了会重建）
　　covers/　　　　　封面缓存
　　archived/　　　　限时书封印后的 zip

最后一句交代：除了你自己打开的那一项「联网查位置」，这个软件不联网、不上传、不需要账号 ——
书、进度、时长、成就全在你自己的机器上。

（这本手册自身的源文件就在仓库的 docs/ 里；开发用的书架默认只有它这一本。
想把它恢复成「只有这本手册」的样子：跑一下打包目录里的 seed_dev_shelf.py 就行。）
