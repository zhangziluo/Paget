### 4. 阅读页（`Reader.tsx`）
- 内核 `text` 取正文（**行号是唯一坐标**），跳章节（`toc`）、书签增删跳、每分钟自动写回 `position`（含书签），

  点**屏幕中间**（`MIDDLE_BAND`：x 25%~75% / y 18%~82%）才呼出 / 收起；点边缘、点书签、
  拖选文字、点顶栏自己都不触发。顶栏不占布局，呼出时书页不跳。
- **一次性消息**（错误 / 提示 / 🏆 / 正在往下接）改成底部浮字 `.reader-toasts`。
- **光点导读**（「跟着光读」）：沿当前行从左往右、在**正文下方**走**一位「领路的」**——
  **光点**（默认，一颗 14px 琥珀小球）、**下划线**或者**波浪线**（后两样都是**没有实体的那一位**：
  **四五个字宽的一小段线自己就是领路的** —— 与已读行那条同色同粗，走法 / 宽度 / 步子 / 伸缩
  **完全共用一套**，只是笔迹一条是墨色直条、一条是波浪；见「决策演变史」2026-10-09 与
  2026-10-10 那两条）。
  划过的轨迹是**字底下一条琥珀下划线**（已读行由 `.reading-line-text` 的 `text-decoration` 画：
  折行时一折一条、只到文字本身；当前行那条是量出来的一折一条 `.reading-guide-trail`，
  走过的整条亮、正在走的那折按进度长；空行没有字就两样都不画）——
  （从前还有二号**兔子**（像素风、一串脚印当轨迹）：2026-10-10 按用户要求去掉，
  老记录里的 `rabbit` 按坏值回落成光点 —— 见「决策演变史」那条）；
  **换成下划线 / 波浪线时那一段线自己就是轨迹**（四五个字宽，与这条同色同粗同高；
  已读行那条在这个模式下**不再常驻**：亮一下就在 0.75s 内化掉，正文里任何一刻
  只看得到那一小段 —— 见「决策演变史」2026-10-09 与 2026-10-10 那两条）；
  **20 档速度按「每行停留时间」**
  （`1` 最慢 20s/行 … `20` 最快 0.5s/行等比排，默认 `10` 档 ≈ 3.5s/行），
  **顶栏那枚「速度」按钮点开**：里面是**标记胶囊（光点 / 下划线 / 波浪线）+ 一根 1–20 的滑杆**（按钮上写着当前档位），
  键盘 `1–6` 是滑杆上的六个快捷档、`0` 开关，顶栏那枚开关上写着当前标记（`光点开 / 下划线开 / 波浪线开`）；
  换档 / 换标记 / 开关时左上方淡入档位牌（如「10档 · 3.5s/行」），2 秒后淡出；
  换档时**当前行重新计时、不跳行**，拖滑杆连发的那串进度**等手停下来再写**（400ms 防抖，
  换标记是点一下，当场写）。
  到达行尾自动换下一行，**空行一条都不花时间、一步跨过去**（空行只是排版留下的缝；开书恢复
  或手滚停在空行上也当帧纠正到后面第一条有字的行，所以段与段之间不会「停顿一下」），
  读到这一批末尾会自动接下一批，**到书末停下**并提示「已到最后一页」（书尾那几行空行也不再白等）。
  光点进度存本机 `localStorage`（键 `paget.reading-guide.v1.<书 id>`，每换一行写一次 + 离开时再写；
  记录里带 `rev`，档位刻度从 6 档换成 20 档时靠它把老记录换算过来、**不换键名**；
  `marker` 是纯新增字段，老记录没有就回光点），
  重新打开同一本书**从上次那一行接着导**（导读关着时才按 `gui_position` / 内核行号恢复）。
  手动滚动 / 跳章 / 翻行后，光点跟到屏顶那一行重新计时；光点自己往前爬时会把当前行留在
  视野上方约 1/3 处（一次挪一行上下）。
  纯逻辑在 `lib/readingGuide.ts`（20 档刻度 / 三种标记 / `stepGuideClock` / `guideDotAt` / `guideTrailAt` /
  `guideTrailY` / **那一段线的 `guideBreath` / `guideCrawlWidth` / `guideCrawlAt`** /
  进度读写与老刻度换算），
  移动与轨迹在 `views/Reader.tsx`（下划线 / 波浪线两号**共用一套走法**，只有模式类不同：
  `guide-crawl` / `guide-wave`），
  样式在 `App.css` 的「光点导读」一节（含顶栏那枚速度按钮与它的小浮层、`.guide-crawl`、
  `.guide-wave`、那条 `reading-guide-ink-fade` 与 `reading-guide-wave-fade`）；
  波浪的形状在 `src/assets/guide-wave.svg`（可平铺的正弦波，拿去做 `mask`、颜色仍由 CSS 给）。
  明确**不做**：小精灵 / 拖尾粒子 / 点击跳转行。
- **书页拟物（外框全静态）**：左侧封面 `.book-cover` + 右下探出的书页堆叠 / 书口 `.book-stack`
  + 当前纸页 `.reader-page`（右侧封底随栏数一起删了）。
- **没有任何翻页动效**：`.reader-sheet` 与 `sheet-next` / `sheet-prev` 随分页一起删掉；
  阅读页只留丝带落下、位置牌 / 提示淡入这几个小动效。

### 9. 打包
- **内核源码就在仓库里**（`core/`，2026-10-11 起；原先是仓库外并排的 `../wreader`）：
  `packaging/build-core.sh` 默认就冻它 —— 找解释器（`$PAGET_CORE_PYTHON` → `core/.venv` → PATH）
  → 临时目录跑 PyInstaller（`paget-core.spec`）→ 装到 `src-tauri/binaries/paget-core/`
  → `smoke_core.py` 真发一轮协议验证。`PAGET_CORE_ROOT` / `--core-root` 仍可指向别处。
- `tauri.conf.json` 把该目录当资源发（`binaries/paget-core` → `core`），macOS 落
  `Contents/Resources/core/paget-core`。**用户机器上不用装 Python。**
- 实测（2026-10-04，Intel macOS，rustc 1.87；2026-10-11 重新冻过一次、产物改名 paget-core）：
  冻结点 onedir 4.6 MB + `_internal/` 共 34 MB；
  `.app` 40.7 MiB / `.dmg` 18.3 MiB；起来后跑的是随包内核，无任何 `python` 进程。
- **Windows（2026-10-07 第十二轮）**：`packaging/build_core.py` 是 `build-core.sh` 的跨平台孪生
  （Windows 上没有 bash、venv 在 `Scripts/`），`packaging/build_windows.py` 一条命令走完全程
  （查环境 → `npm ci` → 冻内核 → `tauri build --bundles msi nsis` → 报产物）。
  Windows 专属配置在 `src-tauri/tauri.windows.conf.json`（只打 msi + nsis、MSI 语言 `zh-CN`、
  NSIS 语言 `SimpChinese` 且按当前用户装、`upgradeCode` 写死）。没有 Windows 机器时走
  `.github/workflows/windows-installer.yml`（`windows-latest`；内核已在同一仓库里，
  **不再**单独 checkout 第二个仓库；2026-10-13 复核时加了最小权限、`timeout-minutes: 90`、
  npm / pip 缓存，以及 MSI 之前那个「尽力打开 VBSCRIPT」的 step；同一天第一次真跑
  （推 `v0.1.0` 标签）挂在 `UnicodeEncodeError` —— Windows 上管道走 cp1252，脚本打不出中文与
  「←」：三个打包脚本各自把 stdio 钉成 UTF-8，工作流再加 `PYTHONIOENCODING: utf-8` 兜底；
  **冻结点内核不用动**（PyInstaller 换过的 stdio 本来就是 UTF-8）—— 见 `activeContext.md` 那一节）。
  **`.msi` 只能在 Windows 上打**（WiX 只在 Windows 上跑），随包内核也必须在 Windows 上冻
  （PyInstaller 不能交叉编译）—— 本机 macOS 只能验到「配置能被 CLI 读进去 + 脚本跑得通」。
